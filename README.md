# postgres-dba-labs

Self-directed PostgreSQL administration practice.

Environment: WSL2 Ubuntu 26.04, PostgreSQL 18 (PGDG), ~3.7 GiB RAM.

| Lab | Focus | Status |
|---|---|---|
| 01-instance-setup | Installation, configuration, roles, host-based auth | in progress |
| 02-backup-recovery | Logical and physical backup, WAL archiving, PITR | not started |
| 03-replication | Streaming replication, replication slots, failover | not started |
| 04-performance-monitoring | Query tuning, pg_stat_statements, autovacuum, monitoring | not started |
